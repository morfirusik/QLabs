# QLabs · Сауле-апа

Работающий прототип для хакатона: симулированная переписка, обнаружение реквизитов и признаков мошенничества, очередь аналитика и связи между переписками. Реальные сообщения и решения в антифрод-центр не отправляются.

Публичное демо на GitHub Pages: `https://morfirusik.github.io/QLabs/`. Эта версия работает целиком в браузере и сохраняет переписки в `localStorage` вашего устройства. Распознавание изображений доступно в серверной версии ниже.

## Запуск

Требуется Python 3.10+. Сторонние Python-пакеты не нужны.

```bash
python3 main.py
```

Откройте `http://localhost:8000`. Порт можно задать переменной `PORT`; путь к базе SQLite — `QLABS_DB`. База создаётся в `data/` при первом запуске. Для распознавания изображений нужен установленный Tesseract. Запустите `bash setup_ocr.sh`, чтобы загрузить проверяемые по SHA-256 языковые пакеты английского, русского и казахского. В текущей среде они уже установлены.

## Сценарий демо

1. Создайте чат «Выплата от ЕНПФ», выберите «Компенсации».
2. Напишите: «Вам положена компенсация от ЕНПФ, но сначала оплатите страховку 2000 тенге. Только сегодня».
3. На вопрос апы о реквизитах ответьте: «Переведите на карту 4111 1111 1111 1111».
4. Посмотрите высокий риск, найденную карту и связь с заранее созданным вымышленным чатом о пирамиде.
5. Нажмите «Передать в антифрод». Приложение сохранит статус локально; внешней передачи нет.

Риск рассчитывается по прозрачным правилам и показывает причины. Реквизиты сами по себе не означают мошенничество: итоговое решение принимает аналитик. Ответы апы формируются локальным сценарием без API-ключа. Демо-карта — стандартный тестовый номер платёжной системы.

Проверка логики: `python3 -m unittest -v test_main.py`.
